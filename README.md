# Col-gio-Analice-Barros
Landing page de alta conversão para o **Colégio Analice Barros**, instituição de Educação Infantil com ensino fundamentado em princípios cristãos. Projeto desenvolvido com foco em apresentar a proposta pedagógica, transmitir confiança às famílias e incentivar novas matrículas por meio de uma experiência digital moderna, acolhedora e estratégica.
